Underlag som hämtades

      Beteckningen hittar du i dokument från riksdagen, t.ex. “bet. 2025/26:AU10”. Ange bara koden (AU10).

      Officiell statistik hämtad live från SCB:s öppna API (PxWeb).

      Datakällor: Riksdagens öppna data · SCB PxWebApi. Appen är helt statisk — all datahämtning sker i din webbläsare. AI-svar kan innehålla fel; kontrollera alltid mot källänkarna.
